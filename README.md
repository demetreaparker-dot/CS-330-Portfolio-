# CS 330 – Computational Graphics and Visualization

## Project Overview

For my CS 330 portfolio, I selected my final 3D scene project, which was inspired by Five Nights at Freddy's. Throughout this course, I used C++ and OpenGL to develop a 3D environment using basic geometric shapes, transformations, textures, lighting, and camera controls. This project helped me understand how different programming techniques work together to create a visual environment.

## How Do I Approach Designing Software?

When designing software, I like to start by understanding what I want the finished project to accomplish and then break the work into smaller steps. Before taking CS 330, I had limited experience creating 3D environments, so this project challenged me to think differently about software design.

One of the new skills I developed was learning how to take a two-dimensional reference image and identify the basic geometric shapes needed to recreate objects in three dimensions. For my project, I had to think about how spheres, cylinders, and other shapes could be combined to create a recognizable character and scene.

My design process involved planning the objects, building their basic structures, adjusting their positions and sizes, and then adding textures and lighting to improve their appearance. I also had to consider the placement of the camera so users could view the environment from different perspectives.

In future projects, I can apply this same approach by planning the overall structure before writing code and developing complicated features in smaller, manageable stages.

## How Do I Approach Developing Programs?

Throughout this course, I learned that developing programs requires patience, testing, and a willingness to make adjustments. My 3D scene did not come together all at once. Instead, I worked through several milestones that gradually introduced new features and programming techniques.

I started by working with basic shapes and transformations. As the course progressed, I added camera navigation, texture mapping, and lighting. I also learned more about shaders and how they affect the appearance of objects in a 3D environment.

One of my biggest challenges was troubleshooting errors in Visual Studio. There were times when my program would not build correctly or the scene would not display as expected. I had to review my code, identify possible problems, and make corrections before testing again.

Iteration played an important role in my development process. For example, I made several adjustments to the appearance of my animatronic model, including its textures, eyes, teeth, and lighting. Each change helped me improve the scene and better understand how different parts of the program worked together.

By the end of the course, I became more comfortable making changes to existing code and testing those changes instead of trying to complete everything at once. This experience strengthened my debugging skills and showed me the importance of developing software through continuous improvement.

## How Can Computer Science Help Me Reach My Goals?

Computer science is helping me build the knowledge and technical skills I need for a career in software development. CS 330 introduced me to an area of programming that I had not explored in much detail before: computational graphics and visualization.

From an educational perspective, learning OpenGL helped me understand how mathematical concepts, programming logic, and visual design work together. I gained experience working with coordinate systems, transformations, lighting, textures, and camera movement. These skills connect to other areas of computer science and helped me see how concepts from different courses can be applied in a practical project.

From a professional perspective, the skills I developed could be useful in software engineering, game development, simulation, and other applications that use interactive graphics. Although I am still exploring different areas of computer science, I enjoyed seeing how C++ code could create and control objects in a virtual environment.

This course also strengthened my problem-solving skills. Learning how to troubleshoot rendering problems and organize a larger project will help me in future programming assignments and professional development.

## Final Reflection

Overall, CS 330 was a challenging but rewarding course. I enjoyed being able to see the results of my programming work on the screen rather than only viewing output in a terminal.

Creating my 3D scene helped me become more confident with C++, OpenGL, and the software development process. It also taught me that even small adjustments can make a significant difference in how a program looks and functions.

I plan to continue improving my programming skills and use what I learned in this course as I work toward completing my computer science degree and pursuing a career in software development.
